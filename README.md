# 🍽️ Restaurant Management System

A beginner-friendly Restaurant Management System built using Python and MySQL.

This project is developed as a first-year college project to understand the basics of Python programming, database connectivity, CRUD operations, and order management.

## 📌 Features

- View Menu
- Add Food Item
- Update Food Item
- Delete Food Item
- Add Customer
- Place Order
- Multiple Items in One Order
- Automatic Bill Calculation
- Store Orders in MySQL Database

## 🛠️ Technologies Used

- Python
- MySQL
- MySQL Connector
- SQL
